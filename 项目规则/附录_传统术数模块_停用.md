# 传统术数模块历史细则（停用）

以下保留整理前原文供追溯，不参与当前预测。文中15%权重及比分、总进球条款不生效。未来启用须确认映射、可复核起局及与现行两项范围一致的实施方案。

## 十六、传统术数辅助预测模块

### 1. 基本定位

术数模块与数据模型严格分离。数据模型始终优先分析实力、排名、积分形势、交锋、状态、主客场、伤停、首发、战术、赛程体能、赔率热度和开放度。

术数只能用于：

1. 胜负方向复核；
2. 冷门提示；
3. 比赛走势辅助判断；
4. 比分区间修正；
5. 总进球区间修正。

不得因卦象忽略现实足球数据。

### 2. 固定术数框架与优先级

1. 奇门遁甲：主判胜负方向和总体走势；
2. 大六壬：复核胜负、转折和领先后走势；
3. 六爻纳甲：修正比分、双方进球和总进球区间；
4. 梅花易数：仅作轻量辅助。

术数内部优先级固定为：奇门遁甲 > 大六壬 > 六爻 > 梅花易数。不得按想要的结果临时更换优先级。

### 3. 起局规则

每场必须以比赛当地实际开球时间和实际地点独立起局，并保存：

- 比赛日期；
- 当地开球时间；
- 北京时间；
- 比赛地点；
- 主客队顺序；
- 原始起局数据及赛前解释。

延期、改场或开球时间变化后，必须按最终实际信息重新起局，并保留旧记录及变更原因。

### 4. 主客取用神规则

必须在启用术数前选定并冻结一套主客映射。用户曾给出的示例是“主队=日干/主方宫位，客队=时干/客方宫位”，但尚未最终确认采用该示例还是另一套规则。

因此新项目的默认状态为：在用户确认固定映射且系统能够保存可复核起局前，术数权重为0%，不得编造术数结论。确认后所有比赛统一使用，禁止临时交换主客位置或赛后反推取用神。

### 5. 固定分析项目

奇门遁甲固定分析：主客落宫、旺衰、五行生克、九星、八门、九神、值符、值使、空亡、入墓、击刑、门迫、伏吟、反吟及主客宫生克。输出先机、先进球、上下半场走势、平局、追平、逆转、开放度、赢不穿和爆冷信号。

大六壬固定复核：三传、四课、贵神、涉害、遥克、昴星、伏吟、反吟。主要判断奇门方向是否得到支持、是否僵持、是否后程反超及是否强弱反转。若与奇门完全冲突，标记“术数内部冲突，高波动”。

六爻主要判断双方进球、大小球、一球差或两球差、平局及比分区间，不单独承担胜平负主判。

### 6. 融合和权重

启用后必须分别输出：

- 数据模型结论：胜／平／负；
- 术数模型结论：胜／平／负；
- 一致性等级及对最终风险的影响。

处理原则：

- 强一致：只可小幅提高方向信心；
- 部分一致：维持数据方向，同时提高相反结果防范；
- 强冲突：标记“数据与术数强冲突”，不得列稳胆，可作为冷门观察，不得强行改写数据解释。

初始总权重：数据模型85%，术数模型15%。术数内部：奇门50%、大六壬30%、六爻15%、梅花5%。权重只能根据长期、独立、足量的赛后统计调整。

### 7. 术数独立复盘

分别统计：

1. 奇门胜平负命中率；
2. 大六壬复核命中率；
3. 六爻比分区间命中率；
4. 术数冷门提示命中率；
5. 数据与术数一致时命中率；
6. 数据与术数冲突时哪一方更准确。

长期无增益则降低术数权重；特定场景有稳定增益时，只能在该场景内调整。

### 8. 术数禁止事项

禁止赛后重解卦象使其看似预测正确；禁止修改原始起局；禁止根据终场比分反推取用神；禁止临时交换主客；禁止同一卦象结果导向解释；禁止编造球员出生时间、五行或命理资料；禁止仅凭卦象建议高额投注。
